Get a Gemini API key

An API key is like a password that lets this app use Gemini on your account. Keep it secret.

  1. Open Google AI Studio

    Go to aistudio.google.com/api-keys, sign in, and accept the terms.

  2. Create a key

    Click Create API key. Choose an existing Google Cloud project, create a new one, or import one as needed.

  3. Store it as a Secret

    In Replit, open the Tools pane, choose Setup > Secrets > New Secret. Name it GEMINI_API_KEY and paste the key as the value.

  4. Restart the app

    Restart so the server reads the new secret. The badge at the top should say "Key configured".
The key stays on the server only. This page never asks for it, never stores it in your browser, and never shows it. A configured key is not proof the key is valid: running a prompt is the real test.
Before class: school Google accounts, age limits, or your region may block AI Studio. Free quota limits apply and billing may apply on some projects. Do not send personal student data (names, grades, contact details) in prompts.

Run it on your own computer

The whole app is exactly two files:

  • server.mjs — a small Node server (built-in modules only) that keeps the key and calls Gemini. Download
  • index.html — this page, with all its styles and script inside. Download

Put both in one folder, install Node 22 or newer, set the key in your environment, then run:

# macOS / Linux
GEMINI_API_KEY=your-key node server.mjs

# Windows PowerShell
$env:GEMINI_API_KEY="your-key"; node server.mjs

Then open the address the server prints. No npm install needed.
